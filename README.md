Desenvolvido com <strong>HTML5, CSS3 e JavaScript puro (Vanilla JS)</strong> com foco em performance, responsividade e acessibilidade.
</p>

<hr/>

<h2>📌 Sobre o Projeto</h2>

<p>
Este é meu portfólio pessoal, criado com o objetivo de apresentar minhas habilidades técnicas, projetos e trajetória na área de desenvolvimento de software.
</p>

<p>
Apesar do meu foco principal ser <strong>Desenvolvimento Backend com C# e .NET</strong>, migrei este projeto de Blazor WebAssembly para <strong>HTML5, CSS3 e JavaScript puro</strong> visando carregamento instantâneo, melhor SEO, acessibilidade (WCAG) e domínio sólido dos fundamentos da web.
</p>

<hr/>

<h2>🚀 Tecnologias Utilizadas</h2>

<h3>🔹 Frontend</h3>
<ul>
  <li>HTML5 (Semântico e Acessível)</li>
  <li>CSS3 (Variáveis CSS, Flexbox, Grid Layout, Animações e Design Responsivo)</li>
  <li>JavaScript (ES6+ / Vanilla JS)</li>
</ul>

<h3>🔹 Ícones & Tipografia</h3>
<ul>
  <li>Font Awesome</li>
  <li>Devicon</li>
</ul>

<h3>🔹 Ferramentas</h3>
<ul>
  <li>Git</li>
  <li>GitHub</li>
  <li>Visual Studio</li>
</ul>

<hr/>

<h2>🎯 Objetivo do Projeto</h2>

<ul>
  <li>Consolidar fundamentos de HTML5, CSS3 e JavaScript puro sem dependência de frameworks</li>
  <li>Aplicar boas práticas de responsividade (Mobile-First) e acessibilidade web</li>
  <li>Garantir alta performance e carregamento rápido em produção</li>
  <li>Construir uma identidade profissional online</li>
  <li>Demonstrar evolução técnica e projetos desenvolvidos na área de tecnologia</li>
</ul>
